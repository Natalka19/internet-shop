# Internet Shop

A simple CRUD web application for managing products in an online store.

## Features
- Add, edit and delete products
- Upload product images with preview
- Remove or replace images while editing
- Search products by name
- Sort products by name, category and price
- Automatic total price calculation
- Data persistence using localStorage

## Technologies
- HTML5
- CSS3
- JavaScript (ES Modules)
- Bootstrap 5
- localStorage API

## How to run
Just open `main-page.html` in your browser.
